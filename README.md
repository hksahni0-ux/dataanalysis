# Data Analysis

A collection of interactive data science and quality-engineering practice notebooks covering EDA, statistics, DOE, SPC/capability, MSA, reliability, and ML — with an AI-assisted guided analysis flow.

## What it does

- Guided analysis flow: describe your problem, get AI-recommended sections to run, view results in an interactive dashboard
- Covers EDA, Statistics, DOE, SPC/Capability, MSA, Reliability, ML, and Visualization
- Python notebook (Colab-ready) plus an R notebook covering equivalent quality-engineering tools (DOE, Gauge R&R, SPC, Capability, Reliability)
- Supporting reference material on quality/design concepts

## Stack

Python (pandas, scipy, statsmodels, scikit-learn, seaborn) · R (FrF2, qcc, SixSigma, ggplot2, shiny) · Groq AI · Jupyter/Colab
